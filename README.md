# Store API

A REST-only backend for a small online store, built with Laravel.

Features (delivered incrementally, one pull request per feature):

- Phone-number authentication with OTP phone verification and password reset
- Admin product management with image upload
- New-product and back-in-stock notifications
- Atomic order creation with concurrency-safe stock handling
- Order status workflow with an audit history and owner notifications

Full setup instructions and the API contract (Postman collection) are added in the
documentation pull request. See the open/merged pull requests for the feature breakdown.
